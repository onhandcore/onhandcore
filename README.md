# OnHand Core

OnHand develops an external Skill ecosystem for AI Agent Hosts.

## Published products / 已正式发布产品

### [OnHandThoroughfare · 中央大道](https://github.com/onhandcore/OnHandThoroughfare)

The **WHERE + HOW** connection and mechanical transport core of the OnHand external Skill matrix. One entry point connects reviewed, formally attached external Skills, with portable Skill-area management and Host-governed invocation.

OnHand 外置技能矩阵的 **WHERE + HOW** 连接与机械转运核心：一个入口连接经审查、正式挂载的外置 Skill，支持技能区携带及由 Host 决策的调用。

First public release / 首次正式公开发布：2026-10-24.

### [OnHandBestFitTool](https://github.com/onhandcore/OnHandBestFitTool)

**WHO:** filters external Skill candidates from legitimate reviewed capability facts; the Host retains semantics, authorization, final selection, and execution decisions. BestFit can run independently in **Standalone** mode or combine with a separately installed compatible OnHandThoroughfare for **WHERE + HOW** mechanical wiring and transport.

**WHO：** 根据合法受审能力事实筛选外置 Skill 候选；Host 保留语义、授权、最终选择及执行决策。BestFit 可以 **Standalone 独立运行**，也可与另装的兼容中央大道组合，由中央大道负责 **WHERE + HOW** 机械接线与转运。

First public release / 首次正式公开发布：2026-10-24.
